If the shaders are purple, you need to import AudioLink into your scene.

https://github.com/llealloo/vrc-udon-audio-link

If you want to use this shaders on a different object you will have to set up the UV's or use the mesh that comes in the shader folder.
The UVs used for the shader are UV 1 and UV 3, not UV 2, because it's used for light maps.
